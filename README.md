# MiraiPlayer

将 `ui/music-player-glass-vs-minimal.html` 的原稿迁入 Tauri 2、Vue 3、TypeScript 和 Tailwind CSS v4。沿用原稿字体、玻璃材质与播放器动效，标题栏按 Windows 调整。

## 代码组织

```text
src/
  layouts/player-layout.vue        # 公共播放器宿主、路由缓存和桌面通信
  pages/index/index.vue            # 首页推荐和歌曲列表
  pages/index/components/          # 首页专用主打横幅
  pages/library/index.vue          # 音乐库
  pages/library/components/        # 音乐库专用智能歌单
  pages/search.vue                 # 其余独立页面按业务名直接放置
  pages/desktop.vue                # 独立歌词、迷你播放器和媒体卡片
  pages/settings/index.vue         # 原生设置窗、分类导航、草稿与底栏提交
  pages/settings/components/      # 设置窗专用表单，复用原稿控件
  components/player/               # 跨页面播放器布局、曲目列表、队列及业务标签
  components/ui/                   # 公共按钮、v-model 标签条、分页和通知
  composables/usePlayer.ts         # 类型化播放器上下文

  stores/player.ts                 # Pinia 中的唯一播放、队列和页面状态
  constants/music.ts               # 默认封面与空播放状态
  services/player/runtime.js       # 原稿播放时序、歌词跟随与动画协调
  services/player/fullscreen-motion.js # 原稿全屏分层切歌动画
  services/player/desktop-motion.js # 原稿桌面切歌与歌词动画
  services/desktop.ts              # Tauri 原生窗口调用
  utils/http.ts                    # Axios 请求工厂及统一错误处理
  api/index.ts                     # 业务接口路径、参数和响应类型
  styles/main.css                  # Tailwind 入口与宿主尺寸
  styles/theme.css                 # 原稿颜色和本地字体令牌
  styles/player-effects.css        # 玻璃材质、状态覆盖、伪元素及原始动画

  app.rs                          # 插件、命令和生命周期组装
```

每个完整页面有真实 Vue Router 路由，切页保留播放和表单状态。需要私有组件的首页和音乐库使用 `pages/业务名/index.vue` 与就近的 `components/`；其余页面直接使用 `pages/业务名.vue`。歌曲、队列、导入、上传、下载和自建歌单由 Vue 列表渲染，公共标签与分页提供 `v-model`。

布局、尺寸、间距和常规排版使用模板中的 Tailwind utilities。复杂玻璃材质、主题覆盖、CSS 变量变换及动画保留原 CSS 级联。切歌继续使用原 Web Animations 关键帧、延迟和曲线；保留旧封面幽灵、连续切歌取消、歌词跟随、光带、视差和减少动态效果设置。

Windows 标题栏移除红黄绿装饰，使用最小化、最大化/还原、关闭按钮；顶栏搜索为 13px，宽度随窗口调整。原网页的 Manrope、Noto Sans SC 和 JetBrains Mono 本地打包，授权在 `public/font-licenses/`。五张原图以相同 WebP 数据保存在 `public/images/`。

Windows 10 主窗口使用 8px 圆角、透明阴影留白和柔和外阴影，保持原内容区域的默认尺寸；最大化时取消留白、圆角与自绘阴影，还原后恢复。Windows 11 按原生构建号识别，使用系统圆角和阴影。透明区域内侧补有八方向缩放入口。

Windows 10 阴影留白通过原生鼠标命中计算切换穿透，点击交给下面的窗口；内容区恢复正常操作，拖动或缩放捕获期间保持交互。设置窗口复用同一套外框处理。全屏播放页顶部增加原生拖动区域，返回和队列按钮保留点击行为。

全屏页保留原稿的封面呼吸、粒子、视差和分层切歌动画。歌词工具提供译文开关与居中阅读模式；首尾留出自适应滚动空间，当前句不再因为内容较少而贴在顶部。手动浏览显示「回到当前」，停留约 3.2 秒后恢复跟随；键盘焦点停留在歌词上时不抢滚动。歌词使用原生按钮，支持上下方向键、Home/End 和回车/空格跳到指定句，不触发全局音量快捷键。高亮主要使用透明度与轻微缩放，关闭动效或系统减少动态效果时禁用歌词过渡和平滑滚动。暂停时背景漂移也暂停。在线封面可复用频谱取色缓存调整环境色，无 CORS 或取色失败时保持原有回退；不增加音频分析管线，也不把逐行 LRC 冒充逐字同步。阅读与译文开关只保留当前页面会话状态。

设置使用独立 Tauri 原生窗口，主界面继续播放并保留当前页面。窗口按“通用、音质、缓存与下载、外观、桌面、快捷键、关于”分类，右侧内容独立滚动，底栏固定。原稿卡片、开关、滑动标签和字体保持不变；重置修改本窗口草稿，应用将整份偏好同步回主播放器，保存应用后关闭，取消放弃未应用的改动。

在线搜索、公开歌单导入及曲目点播使用 MiraiMusic-Server 的 FastAPI。导入歌单保存于当前播放器的本机存储，播放权限以原平台当次返回为准。首次启动曲库为空；本地文件页仅支持当前会话的曲目资料登记。下载页显示原生文件记录，天气使用用户当前位置的接口数据。

在标题栏或搜索页输入后按回车或点击放大镜提交。「平台对接」统一使用含「登录平台 / 主页链接」的弹窗，网易云和酷狗优先展示扫码，酷我使用公开主页。关联记录和完整导入的公开歌单保存在本机。

无需登录也可在「粘贴分享内容」直接粘贴 App 分享文字或多行公开歌单详情链接，每批最多 50 个；自动提取链接、去重并逐份完整保存。已导入歌单仍可勾选更新，账号歌单通过独立选择弹窗展示，支持全选/取消本页、部分选择并保留其他分页选择，列表标题统一为 13px。单项失败不阻断后续歌单，统一通知批次结果并可仅重试未完成项；主动停止或离开页面不会丢失已保存的歌单，旧请求不能写入新批次。每份歌单完整读取成功后才覆盖旧版本。批量导入留在当前页，单链接全部成功时自动打开歌单。短链接暂不展开；重试队列属于当前页面会话，刷新应用后不保留。

| ------ | ----------------------------------------------- | -------------- | ---------------- |
| 网易云 | 已接入真实二维码和上游身份确认                  | 支持           | 支持             |
| 酷我   | 本次不接第三方授权，保留明确未支持提示          | 支持           | 支持             |

网易云与酷狗扫码使用 MiraiMusic-Server 的短期身份接口：二维码由真正的上游 key 在服务端本地生成；只有上游明确确认授权并通过账户 UID 一致性验证，才接受公开资料。网易云继续读取同一 UID 的公开歌单，并将昵称、头像和关联记录一次保存；读取失败可在已确认身份面板重试。酷狗只保存经验证的公开身份，不读取需要 token 的账户歌单，仍支持公开分享链接导入。二维码的「已扫码」不等于身份已确认。

顶栏头像使用 28px 视觉尺寸、36px 点击区域，用户与设置图标统一为 16px，弱化外圈避免抢过窗口按钮。右上只显示公开头像或中性用户图标，不显示固定演示用户；悬停、点击或方向键可打开三个平台选项，支持 Home/End、Escape、焦点移出与外部点击关闭。设置入口在头像旁；侧栏不再包含用户/设置或桌面小窗入口。刷新公开歌单不会丢失同一账号头像，也不会复用另一 UID 的头像。

网易云扫码同时建立本次播放会话。播放器只在内存持有短时点播凭证，服务端隔离保存经核验的上游凭据，期限为四小时。头像旁显示平台确认的会员等级；仅确认会员身份时显示 VIP。重启后公开关联保留，会员播放需要重新扫码。底栏音质选择与设置联动，实际音质、整曲或试听以该账户本次返回为准。酷狗扫码用于关联公开身份。

系统托盘右键显示原生菜单，选择「迷你播放器」「桌面歌词」「媒体控制卡片」分别打开对应小窗；左键恢复主窗，也可在托盘打开设置或明确选择退出。迷你卡失焦或按 Escape 收起。桌面歌词、迷你卡、媒体卡和独立灵动岛可右键「关闭小窗」，只隐藏当前表面，不退出主播放器。四种表面均保留原稿本体尺寸、圆角和四边 32px 透明阴影留白；暗玻璃增强背景遮蔽，小阴影避免底部硬切。CSS `backdrop-filter` 只模糊同一 WebView 内背景，这里没有启用或承诺 Windows 原生桌面 blur。媒体卡仍是原稿模拟 SMTC，不代表已接入 Windows 系统媒体会话。

空曲库引导用户搜索歌曲或导入歌单。底部频谱采用不超过 2px 的细条并跟随歌曲封面主色，播放时使用真实音频分析数据。减少动态效果会停止动画。

平台标识以本地 Iconify SVG 渲染。网易云图形来自 [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/neteasecloudmusic.svg)，酷狗和酷我图形参考其应用图标绘制。 [酷狗音乐](https://apps.apple.com/cn/app/id472208016) · [酷我音乐](https://apps.apple.com/cn/app/id588673713)

## 用户当前位置天气

标题栏与全屏复用同一个天气驱动，使用宿主的 `getCurrentPosition` 获取本次位置，再请求 Open-Meteo 当前天气。不会用固定城市、IP 推测、固定 19° 或演示数据兜底。只有新鲜有效的结果才显示温度。当定位被拒绝、暂不可用或天气接口失败时，胶囊显示原因并支持点击重试。成功以 200ms 淡入/轻移呈现，减少动态效果时不做过渡。

权限查询、一次定位、以及「天气 HTTP + JSON」各有 8 秒预算；约每 15 分钟刷新，两个组件及重复刷新不会叠加请求。权限撤销或宿主明确拒绝时立即隐藏并停止自动重试。位置不落盘、不进入 HMR 快照或日志，发给天气服务前经纬度舍入到约一公里网格；请求不带 Cookie，不发送 referrer，不接受重定向。天气仍依赖用户在宿主/Windows 中允许定位以及可用网络，点击「定位未授权」后，Windows 桌面端将当前播放器来源的定位权限恢复为询问，再请求一次位置。系统禁用位置时，需要在 Windows 的位置设置中开启。Open-Meteo 数据用于当前天气展示，不是本地气象站的精确实测保证。

## 运行和验证

先在 MiraiMusic-Server 仓库启动 `uv run --locked uvicorn main:app`。播放器默认请求 `http://127.0.0.1:8000`，也可以在 Vite 环境中设置 `VITE_APP_BASE_API` 指向其他服务地址。公开歌单导入支持三平台带数字 ID 的歌单详情链接。

```sh
pnpm install
pnpm tauri dev
pnpm build
pnpm check:motion
pnpm check:fullscreen
pnpm check:equalizer
pnpm check:queue-menu
pnpm check:storage
pnpm check:spectrum
pnpm check:desktop
pnpm check:platform-login
pnpm check:platform-import
pnpm check:weather
pnpm check:native
cargo check --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --manifest-path src-tauri/Cargo.toml --lib desktop::
pnpm tauri build --debug --no-bundle
```

`check:equalizer` 为 26 组音频图/参数/跨域回退/生命周期模拟回归；`check:queue-menu` 为 8 组状态/焦点/键盘与 SFC 编译回归；`check:storage` 为 5 组实际 Rust 安全测试。`check:motion` 与原稿核对全屏和桌面切歌的关键帧、时长、延迟、缓动、全屏关闭时序及 CSS 关键帧。`check:fullscreen` 为 11 组实际歌词处理器的模拟键盘/拖动/恢复跟随/焦点回归，不等于原生 WebView 点击验收。`check:platform-login` 为 33 组模拟流程/身份/键盘回归，`check:platform-import` 为 31 组公开资料/批量导入/更新/重试/存储/取消/导航/分页回归，`check:weather` 为 65 组模拟定位/数据/生命周期/组件检查；它们不代表真人扫码或定位授权已通过。`check:desktop` 保留原桌面检查，并追加 12 组头像菜单模拟、2 组连接弹窗初始化回归及 7 个 SFC 的编译验证。

构建还会自动执行 [压缩 CSS 检查](scripts/check-built-css.mjs)，确认三张桌面卡片及灵动岛的标准 `backdrop-filter` 声明仍保留。WebKit 前缀后写可能使压缩产物只剩该前缀，而当前 WebView 不识别它；源声明顺序已修正，验收仍以实际 WebView 的计算样式为准。

Windows 下 `check:native` 需要已安装的 Windows SDK `mt.exe`：Tauri 的单元测试产物未自动携带应用已有的 Common-Controls v6 声明，可能在载入 `TaskDialogIndirect` 时以 `0xc0000139` 退出。脚本从 Cargo 输出定位且校验本项目的测试 EXE，只为该生成产物补相同声明，再运行真实 Rust 桌面单元测试；不修改主程序、源码或系统库，也不会安装 SDK。这与真实托盘/UIA 点击验收仍是不同层面的验证。前端单独预览使用 `pnpm dev`。浏览器与 Tauri 开发都使用 `127.0.0.1:1420`，FastAPI 按此来源放行跨域请求。`pnpm tauri dev` 会自动启动 Vite。Windows 调试应用输出为 `src-tauri/target/debug/miraiplayer.exe`。


## 新增队列、EQ 与存储

- 底栏播放队列在主窗口右下角展开，不改变页面或全屏状态。可点击播放、下一首播放、拖动排序，支持方向键、Home/End、Escape 和焦点返回；全屏页保留自己的队列面板。
- 阅读模式与译文切换使用可打断的 120ms 淡出和 180ms 淡入。弹窗与设置分类也有短淡入淡出；系统减少动态效果或关闭动效时静态显示。后续代码遵循 [项目约定](<AGENTS.md>)。
- EQ 默认关闭。十个频段为 31/62/125/250/500/1k/2k/4k/8k/16kHz，范围 ±12dB，0.5dB 步进，前级 ±12dB。内置平直、流行、摇滚、电子、爵士、古典、人声、低音增强、明亮、温暖、轻音乐、深夜 12 个预设，每项有用途说明。可双击归零单段、重置曲线、保存最多 20 个自定义预设并确认删除。
- EQ 应用后接入真实 Web Audio 图，参数用 20–80ms 斜坡平滑。自动余量根据相邻滤波器的叠加响应估算并降低前级，不是砖墙 Limiter 或硬件校准。无 CORS、音频权限/Context 失败时明确报告并保持原声，不伪造 EQ 生效；只有一个活动媒体时钟。
- 主窗口缓存已应用偏好、音量、静音、稳定曲目键、队列、收藏、最近播放和公开曲目元数据。恢复位置但不自动播放；设置窗口未应用草稿不覆盖缓存。临时音频 URL、Cookie/token 不保存，原有导入歌单和公开账号关联不清除。
- 桌面版可选择/打开缓存与下载目录，目录先作为草稿、应用/保存后生效。配置落盘，切换目录不迁移或删除旧文件。清理只处理带所有权标记的应用专有音频缓存子目录，不递归删除用户选的目录，也不删除下载、歌单、账号或 EQ。
- 下载页面不再显示固定演示任务与完成统计。可下载当前真实平台歌曲，先检查权限再通过后端音频路由获取、校验音频类型/文件头/长度，原子写入且不覆盖既有文件。单次串行、512MiB/180秒预算；已知试听明确标记，旧后端未确认最终范围/音质时保守标记 unknown，不回显请求音质冒充实际音质。

**范围说明：**自动播放音频落盘缓存、断点续传、下载暂停/取消/实时百分比、应用内自动离线播放尚未接入。旧无缝播放、交叉淡化、响度标准化、睡眠定时和系统输出设备切换仍是预留偏好，页面已明确标注，不代表真实声音处理已实现。浏览器只可验证 UI/偏好，不支持原生目录或下载。

## 哪些开发测试数据可清理

- 可重建候选：关闭对应进程后的 `.tmp/` QA 截图、报告、临时浏览器配置与一次性修改脚本；`dist/`；`src-tauri/target/storage-check-*` 等测试输出和可重新构建的 Cargo 产物。先核对绝对路径、确认确属开发产物，再按需要清理。本次没有自动删除这些目录。
- 保留原稿黄金参考、回归测试脚本、字体授权及界面仍在使用的图片资源。[原稿](<ui/music-player-glass-vs-minimal.html>)
- 用户数据不能作为测试数据删除：已导入歌单、公开账号关联、播放偏好、自定义 EQ、用户选择的下载目录及其文件。
- 已移除内置演示曲库与封面、歌词和模拟播放统计。首页主打使用曲库中的在线歌曲，封面加载失败时显示通用封面。

以上 Node 模拟和 Rust 单元测试不等于真人音源试听、实际系统目录选择或破坏性清理验收。原生新命令需要重新启动/构建桌面程序后使用。

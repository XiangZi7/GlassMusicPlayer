# 下载、缓存与本机数据

## 什么会保存

| 数据 | 保存方式 |
| --- | --- |
| 公开歌单、关联账号的公开资料、播放偏好与 EQ 预设 | 保存在当前设备的播放器数据中 |
| 当前曲目、进度与队列 | 根据稳定歌曲标识恢复，重新启动后由用户决定何时播放 |
| 网易云设备播放授权 | 支持记住登录的 Windows 客户端使用系统凭据管理器 |
| 下载音乐 | 使用已应用的下载目录及原生文件记录 |
| 位置、短期扫码过程和临时音频地址 | 仅在需要它们的会话或请求中使用 |

## 下载曲目

在桌面版下载页对当前在线曲目发起下载。应用先检查平台许可，再读取音频并验证响应、格式和长度。成功后原子写入并显示记录。重名时保留已有文件。上游只返回试听时显示试听；旧服务未明确确认整曲或实际音质时保留未知状态。

默认音质是向上游提出的请求。会员权益、曲目下架、地区和平台当时返回的结果都会影响可用性。浏览器预览只能展示页面，目录选择及文件落盘需要原生桌面版。

## 更改目录或清理缓存

1. 打开“设置 → 缓存与下载”，分别选择音频缓存目录与下载目录。
2. 点击“应用”或“保存设置”后，新操作使用新目录。原目录中的文件保留在原位置。
3. “清理缓存”只处理播放器标记为自有的音频缓存内容。下载、歌单、账号关联和自定义 EQ 各自独立。

当前版本按次处理下载，未提供断点续传或自动播放音频落盘缓存。已导入歌单可离线查看本机记录，实际在线播放仍需要当次有效音源。

## 问题定位

下载失败时先核对当前曲目是否可播、允许的范围和下载目录是否可写。反馈中可提供系统、应用版本、来源平台与公开曲目标识。授权和文件路径不适合写入公开问题。[发行包校验](RELEASING.md)

# 玻璃材质与动效

## 两种材质

在“设置 → 外观 → 玻璃质感”选择跟随窗口、毛玻璃或液态玻璃。“应用”提交并继续调整，“保存设置”提交后关闭窗口。播放器、设置窗及所属窗口内的菜单共用当前材质。

| 模式 | 可以观察的细节 |
| --- | --- |
| 毛玻璃 | 暗色半透明表面、细边和柔和阴影，层级主要由明暗区分 |
| 液态玻璃 | 背景色透过渐变，边框和顶部内高光更亮 |
| 跟随窗口 | 使用所属播放器窗口的默认选择 |

## 外观设置有什么作用

“底栏频谱”控制播放时的音频可视化。“天气胶囊”在标题栏和全屏开启当前位置天气。位置需要用户授权，天气由 Open-Meteo 返回，附近地名由设备上的地理索引匹配。授权失败可以查看提示并重试。“正在播放面板”控制主窗口右侧面板。

## 减少动态效果

关闭“界面动效”或在系统启用减少动态效果，可停止封面浮动、弱化歌词跟随时的过渡。阅读模式也会暂停封面组浮动。音量、进度和均衡器使用连续数值，同一面板无需因每次拖动重新入场。

## 核对材质

可选择一张浅色封面和一张深色封面，分别打开同一个队列弹层，再切换玻璃模式。检查当前曲高亮、文字、边框和键盘焦点是否都清晰。在窄窗口中确认设置内容可以滚到底、保存按钮可达。桌面小窗的 CSS 模糊取景位于自己的 WebView。字体文件、外观与数据授权见[开发文档](DEVELOPMENT.md)。
